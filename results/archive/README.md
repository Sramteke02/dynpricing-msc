## `dashboard-2026-07-16-isoelastic-SUPERSEDED.png`

The three-panel Matplotlib dashboard, generated by `dynpricing dashboard` and
last written in commit `d4af026` ("Re-run experiments under real UCI
calibration"). It is superseded on four counts:

1. **Wrong demand model.** It predates `850ff75` ("Replace isoelastic demand
   with linear"), so it shows results from the **isoelastic** demand model whose
   profit-maximising price is a constant — the structural defect that made a
   fixed price score ~95% of oracle and made the scenarios look identical.
2. **Wrong horizon and inventory.** It predates `229772a` (horizon 90 → 365,
   inventory 12000 → 48000), so its episodes cover a fraction of a seasonal
   cycle.
3. **Wrong price band.** It predates `40e58a7`, which reconciled the band to the
   demand parameters ([0.42, 9.95] → [0.84, 5.97]).
4. **Missing agents.** It has no `gbm_uniform`, so it shows the GBM collapse
   with no control beside it.

Regenerating the static PNG at `results/dashboard.png` from current results is
still supported (`dynpricing dashboard --results results/metrics.csv --out
results/dashboard.png --scenario baseline`); note that
`src/dynpricing/dashboard/plots.py` has no `gbm_uniform` entry in its display
order, so that agent sorts to the end of the ladder.
